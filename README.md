# HNG-Task-0
Built a small, accessible, responsive Profile Card component/page using semantic HTML and modern frontend patterns using plain HTML/CSS/vanilla JS . Every visible element must include a data-testid attribute so automated tests can target it.
Created a responsive profile card (data-testid="test-profile-card") with name, bio, time in milliseconds, avatar, social links, hobbies, and dislikes. Use semantic HTML tags (article, h2, p, ul, li). Ensure accessibility, keyboard focus, and clean layouts across mobile, tablet, and desktop using Flexbox or Grid.
